# Employee Registration Form

A responsive employee registration form built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive layout for mobile, tablet, and desktop
- Validates full name, email address, password, phone number, and department
- Displays field-specific validation messages
- Shows a success message when all fields are valid
- No libraries or installation required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code.

## Files
- `index.html` — form structure
- `style.css` — responsive styling
- `script.js` — client-side validation
- `README.md` — project instructions

## Note
This is a front-end demo. It validates details in the browser but does not save or send employee information to a backend.
